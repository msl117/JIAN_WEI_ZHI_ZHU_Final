# 开源说明

## 交付内容

推荐公开以下内容：

- `README.md` 和 `docs/` 项目说明。
- `td_project/workpiece_inspection.al`、`workpiece_inspection.sdc`。
- `user_source/` 中自行编写的 RTL 和约束。
- `verification/` 中的测试平台源码和运行脚本。

## 不应当混入源码包

- `work/`、`xsim.dir/`、`.Xil/` 和各类工具缓存。
- `*.log`、`*.logw`、`transcript`、`*.jou`、`*.pb`、`*.wdb`。
- TD 的中间数据库、增量综合缓存和历史 run 日志。
- 旧工程副本、临时 Sobel 文件和不在 `.al` 引用清单中的历史源文件。

公开仓库不包含 bit、旧工程运行结果或工具缓存。重新仿真时建议把输出目录放在系统临时目录，不要把缓存写回发布包。

厂商加密 HDL、MIPI/DDR/HDMI IP 和器件库不纳入公开仓库。使用者需通过授权的安路 TD/IP 安装获取或重新生成相关依赖；公开前仍应核对安路及第三方许可。

## 修改规范

1. 不直接修改 MIPI D-PHY、DDR 控制器和 HDMI TX 生成文件，除非能同时提供工具版本和回归结果。
2. 新增 RTL 时在文件开头写清输入输出、时钟域、帧边界行为和资源意图。
3. 修改 `pin.adc`、SDC 或摄像头寄存器表时必须单独记录原因并重新做板级回归。
4. 提交前检查 `.al` 中的路径都能在干净目录解析。
5. 不把仿真通过、综合成功或 bit 生成成功描述为板级验证通过。

## 当前版本声明

当前 `workpiece_inspection.al` 尚未重新生成 bit 和 TD 构建报告；历史构建的 Setup WNS 为负。公开时应把资源/时序风险和板级验证清单一并发布，且不要将历史 bit 视为当前源码的板级验证结果。
