## 4. 时钟和 CDC 审查

工程包含 MIPI RX byte clock、24 MHz 控制/摄像头时钟、100 MHz 系统时钟、DDR 用户时钟、HDMI pixel clock 和 HDMI serial clock。SDC 已将 MIPI 与系统/控制时钟组声明为异步，并对 DDR 时钟单独处理。

需要重点关注：

1. 检测结果从 ISP/控制域到 HDMI 域必须使用稳定数据加事件/toggle 或等价握手。
2. 多位模式、统计量、坐标和 BCD 数据不能逐 bit 独立同步后直接组合使用。
3. HDMI mixer 应在视频帧边界锁存 OSD/框数据，活动视频期间保持稳定。
4. `I_button[3]` 的标定事件需要在目标时钟域形成单周期脉冲。
5. 负 Setup 路径集中在控制结果到 HDMI 的跨域/传递路径，若继续修改应先定位最差路径再决定是否加寄存器或简化数据。
