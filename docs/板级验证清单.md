# 板级验证清单

## 1. 烧录前

- [ ] 确认目标器件为 `PH1P35MDG324`。
- [ ] 重新构建后使用 `workpiece_inspection_Runs/phy_1/workpiece_inspection.bit`，不要误用 `camera_to_dsi_display_Runs/` 中的历史 bit。
- [ ] 记录 bit 文件 SHA-256，并保留烧录版本号。
- [ ] 检查 PH1P35、SC520CS、HDMI 线和显示器供电。
- [ ] 摄像头镜头固定，工件完整落在 ROI 内。

## 2. 上电和基础视频

- [ ] 上电后 HDMI 能显示画面。
- [ ] 原图模式无黑屏、撕裂和明显跳帧。
- [ ] A9 可以在原图和 Sobel 之间切换。
- [ ] D5 增益等级文字变化，图像亮度响应合理。
- [ ] B9 可以依次切换灰度、ROI BINARY、DEBUG ROI。
- [ ] 五种模式文字与画面内容一致。

## 3. ROI 和矩形框

- [ ] ROI 外为黑色，ROI 内阈值分割有效。
- [ ] 固定摄像头时黑像素数量基本稳定。
- [ ] 工件移动时外接矩形跟随移动。
- [ ] 工件旋转后矩形仍包围工件。
- [ ] 工件离开 ROI 后显示 NO OBJECT，矩形消失或无效。
- [ ] 各模式下工件有效时框线不在一帧中途跳变；DEBUG ROI 下额外检查形状信息。

## 4. C7 标定和 SHAPE

- [ ] 将合格工件放稳，短按 C7。
- [ ] 等待面积基准和形状模板都准备完成。
- [ ] 同一工件轻微旋转后重复观察 MATCH、SCORE、ANGLE。
- [ ] 使用明显缺口或明显变形样品，确认 SHAPE 可以进入 NG。
- [ ] 更换工件后观察 RESULT 与 SHAPE 是否分别符合预期。
- [ ] 复位/断电后确认需要重新标定。

## 5. QUALITY 和报警

- [ ] 未标定或无工件时 QUALITY 显示 WAIT，而不是虚假的 0%。
- [ ] 质量分数显示范围为 0% 到 100%。
- [ ] 当前工程等级文字按实际 RTL 为 WAIT/PASS/FAIL。
- [ ] QUALITY 发布 FAIL 后 C12 蜂鸣器响约 500 ms。
- [ ] OK 和 WAIT 不能新触发报警；既有的 500 ms 报警脉冲可能继续至结束。
- [ ] 重复标定后旧评分和旧模板不会继续冒充新结果。

## 6. 稳定性和记录

- [ ] 连续运行至少 30 分钟。
- [ ] 连续切换显示模式和增益，无花屏或图像漂移。
- [ ] 观察低亮度、强亮度、背景颜色变化和红色工件。
- [ ] 记录每项测试的环境、按键动作、屏幕现象和结论。
- [ ] 对失败现象拍摄屏幕和板卡连接照片，并记录发生时间。

板级验证完成前，提交材料应使用“已生成 bit，待板级验证”的表述，而不是“系统已完全验证”。
