# 源码模块说明

## 顶层和时钟

| 文件 | 作用 |
| --- | --- |
| `user_source/hdl_source/design_top_wrapper.v` | 顶层连接、PLL、摄像头上电/I2C、按键、跨时钟域、ISP/DDR/HDMI 和蜂鸣器连接 |
| `user_source/hdl_source/video_in.v` | 将视频流写入 DDR 帧缓存 |
| `user_source/hdl_source/video_out.v` | 从 DDR 读取视频流并提供 HDMI mixer 输入 |
| `user_source/hdl_source/mc_to_user_interface.v` | DDR 控制器和用户视频接口之间的适配 |
| `user_source/hdl_source/signal_delay.v` | 控制信号延迟和时序配合 |
| `user_source/hdl_source/quality_score_ctrl.v` | 消费 ISP 提供的配对结果，在低速域计算评分、等级和计数 |

## 摄像头、MIPI 和 ISP

| 路径/文件 | 作用 |
| --- | --- |
| `mipi_dphy_rx/` | PH1P MIPI D-PHY 接收封装和厂商加密/生成模块 |
| `isp/csi_unpacket_2lane.v` | CSI 数据包解包 |
| `isp/raw10_unpacket_2lane.v` | RAW10 像素解包 |
| `isp/demosaic_4x_2_0/` | Bayer RAW 到 RGB 的去马赛克和行缓存 |
| `awb.v` | AWB 数据通路连接 |
| `isp/isp_top.v` | ISP 分支汇总、帧模式锁存、ROI/检测/形状支路连接和输出选择 |
| `isp/edge_detect_96.v` | 4 像素/拍的 Sobel 边缘处理流水线 |
| `isp/roi_binary_96.v` | 灰度阈值比较和 ROI 外黑色屏蔽 |
| `isp/data96_128/` | 96 bit 四像素流到 DDR/显示所需 128 bit 流的打包 |
| `isp/roi_data_96bit_to_128bit.v` | ROI 视频专用打包 |

## 检测支路

| 文件 | 作用 |
| --- | --- |
| `isp/roi_feature_extract.v` | 统计黑像素数和实时最小/最大 X/Y，输出外接矩形数据 |
| `isp/inspection_decision.v` | 按面积、宽高和连续帧稳定性产生工件存在结果 |
| `isp/inspection_baseline_ctrl.v` | C7 面积基准、相对裕量、面积 RESULT 和 BCD 显示数据 |
| `isp/roi_binary_frame_buffer.v` | 低分辨率轮廓采样缓存，供形状支路读取 |
| `isp/roi_moment_stats.v` | 采样轮廓的面积、矩和边界统计 |
| `isp/roi_axis_calc.v` | 计算主方向和归一化尺寸 |
| `isp/roi_rotate_normalize.v` | 将采样轮廓旋转、缩放到统一 32 x 32 网格 |
| `isp/shape_template_match.v` | C7 学习模板，与当前归一化轮廓比较，并支持方向消歧 |
| `isp/shape_match_fusion.v` | 在完整形状结果就绪后发布 MATCH/NG/WAIT 等状态 |

## 工程管理规则

- `.al` 是 TD 工程入口；源文件是否参与综合以 `.al` 的 `<File Path>` 为准。
- `user_source` 下的厂商 IP、DDR、MIPI 加密文件和存储器生成文件均属于工程输入，不能按“没有被 Verilog include”判断为无用。
- `verification` 下只保留测试平台和脚本；仿真产生的 `xsim.dir`、`work`、`.Xil`、日志和波形不作为源码交付。
- `camera_to_dsi_display_Runs/` 保留旧工程的历史 bit 和报告；当前工程改名后尚未生成 `workpiece_inspection_Runs/` 的新构建结果。
